# ExamHall – Online Examination Platform

A front-end online examination platform with separate admin and student views, built with HTML, CSS and vanilla JavaScript. Data is stored in the browser's `localStorage`.

## Project structure

```
examhall/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── .gitignore
└── README.md
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Tech stack

HTML5, CSS3, JavaScript (ES6+), localStorage
